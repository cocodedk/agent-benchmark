# Security Policy

## Reporting a Vulnerability

Do **not** open a public GitHub issue for security vulnerabilities.

To report a vulnerability:
- Use the **"Report a vulnerability"** button on the Security tab of this repository (GitHub private advisory)
- Or email: [babak@cocode.dk](mailto:babak@cocode.dk)

We will acknowledge within 5 business days and aim to fix the problem within 30 days of confirmation.

## Supported Versions

This project has no releases. Only the latest state of `main` is supported.
